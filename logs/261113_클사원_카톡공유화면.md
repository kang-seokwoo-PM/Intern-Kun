# 261113_클사원_카톡공유화면

1. **요청** (작업 지시 그대로, 핵심 문장):
   - 1차: "Build a mobile HTML mock of the "share to KakaoTalk" screen for a Samsung Fire Direct event landing, in a winter look. It goes into a bidding deck, so it must look like a finished product screen, not a wireframe."
   - 2차(작업 중 추가): "Two more phones will sit next to it to show the spread: (1) the share screen inside the landing page, and (2) the screen as received in KakaoTalk." — 장표 속 폰은 200~240px 폭으로 작게 들어감, 안드로이드 모양(22:27, 펀치홀, 하단 3버튼), 밝은 화면, 보낸 사람 한마디 말풍선 추가, 버튼 "나도 세어 보기", 화면만 PNG(1170x2535)·프레임 PNG·두 폰 나란히 PNG, 그림은 쉽게 바꿀 수 있게.
2. **입력** (받은 자료·출처):
   - 랜딩 v8 HTML (`/root/.claude/uploads/.../215938bc-_____________________v8.html`, 읽기만 함. `rules/03`에 따라 저장소에 넣지 않음)
   - 디자인 토큰: 랜딩 L17-29 (`#0068FF`, `#076FC8`, `#0685CD`, 둥근 모서리 16/20/28px, Pretendard CDN L9)
   - 그림: 랜딩 결과 상단 그림(L246, 800x1235) 1장. 크기는 그대로 두고 JPEG로 다시 압축(160KB)
   - 눈 효과: 랜딩 `startSnow`(L597-618) 구조를 그대로 가져와 그림 영역 안에서만 내리게 줄임
   - 랜딩 안에 "공유" 관련 화면·문구는 **없음**(검색 0건) → 공유 관련 문구는 모두 NEW
3. **산출** (만든 파일·경로):
   - `workspace/강석우/v1_카톡공유화면_겨울.html` (약 242KB, 파일 하나에 다 들어 있음)
   - `workspace/강석우/카톡공유화면_겨울_스크린샷/`
     - `01_화면만_공유화면_1170x2535.png`, `02_화면만_카톡채팅방_1170x2535.png` — 베젤 없음, 장표 속 폰 틀에 넣는 용
     - `03_프레임_공유화면.png`, `04_프레임_카톡채팅방.png` — 검은 두꺼운 베젤 + 펀치홀, 투명 배경

     - 모든 파일 1MB 미만(최대 643KB)
4. **진행** (한 일, 순서대로):
   1. 랜딩에서 토큰·문구·그림·눈 코드 확인.
   2. 1차 시안(어두운 남색 화면) 작성·촬영·수정 — 아직 커밋 전.
   3. 2차 지시를 받고 같은 파일을 고쳐 밝은 화면으로 바꿈: 흰 배경 + 그림 카드 + 흰 공유 시트, 가짜 상태 표시줄(22:27)·하단 3버튼 바, 카톡 말풍선 "언니, 이거 해봤어? …", 버튼 "나도 세어 보기", 글자 크게.
   4. 3배율로 촬영 → 220px 폭으로 줄여서 직접 봄: "16번", 행사명, 노란 카톡 버튼, 카톡 카드 제목 모두 읽힘.
   5. PNG가 1MB를 넘어(공유 화면 1.8MB) 색 수를 줄여 압축. 처음 쓴 방법은 눈밭에 띠 무늬가 생겨 버리고, 더 좋은 압축 도구(libimagequant, 작업 폴더에만 설치)로 다시 함 → 원본과 나란히 놓고 차이 없음 확인.
   6. 동작 확인: 링크 복사 토스트, 카톡 버튼 → 채팅방, 뒤로 → 공유 화면, 시트 닫기/다시 열기, 움직임 줄이기 설정, `?chrome=0`(가짜 바 숨김), `?state=chat`(채팅방 바로 열기). 바깥 요청은 서체 CSS 1건뿐.
5. **판단** (택한 것 / 기각한 것 / 이유):
   - 택함: 결과 상단 그림(L246) 1장을 카드·카톡 이미지에 다르게 잘라 재사용. 그림은 파일 맨 위 `<style id="art">`의 `--art` 한 줄만 바꾸면 교체됨(위치 값 2개 함께).
     기각: 인트로 키비주얼(L207) — 그림 안에 제목 글자가 박혀 있고 폭이 474px라 3배율에선 흐림. 브릿지 그림(L225) — 사람이 없어 "내 이야기" 느낌이 약함.
   - 화면 전체는 밝게, 어두운 남색은 그림 카드 안에만. 따뜻한 색은 그림 속 나무 불빛 하나.
   - 공유 시트 뒤를 어둡게 덮지 않음(흰 장표 위에서 어둡게 보이지 않도록).
   - 보낸 사람 이름을 "딸" → **"동생"**으로 바꿈: 말풍선이 "언니"에게 하는 말이라, 받는 사람 폰에 저장된 이름은 "동생"이 자연스러움.
   - 카톡 버튼 문구: 1차엔 랜딩 CTA(L270)를 썼으나 2차 지시대로 "나도 세어 보기"(NEW)로 바꿈.
   - 펀치홀은 화면만 PNG에는 넣지 않고 프레임 PNG에만 그림(장표 속 기존 폰 틀에 펀치홀이 있으면 겹치지 않게).
   - 삼성화재 표시는 글자만. 진짜 로고 파일이 없어서 아이콘을 지어내지 않음.
   - 파일명: 지시대로 `v1_카톡공유화면_겨울.html`. `rules/02`의 `vN_내용_YYMMDD`(날짜 붙이기)와 다름 — 지시를 따름.
   - 스크린샷 서체: 작업 환경에서 Pretendard CDN 접속이 막혀 있어, 촬영할 때만 같은 버전(1.3.9) 서체 파일을 로컬에서 넣어 찍음. HTML은 랜딩과 같은 CDN 주소 그대로.
