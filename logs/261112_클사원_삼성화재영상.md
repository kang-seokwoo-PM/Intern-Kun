## v3 반영 (261112, 저장소 파일명 `v2_`)

1. **요청**: 광고주 피드백 6건 + 추가 연출 지시(A~H) + 배경음악을 v2에 반영해 재편집.
2. **입력**: 랜딩 v8 HTML (출처: 사용자 제공), 기존 v2 렌더 파이프라인.
3. **산출**: `workspace/강석우/v2_삼성화재_남은겨울_16x9.mp4` — 16:9, 1920×1080, 71.4초, 약 38.0MB, H.264 + AAC 192k (출처: ffprobe 측정). 내부 버전명은 v3. 기존 `v1_` 파일은 그대로 둠.
4. **바뀐 것**:
   - 행사명 "우리가 함께할 겨울"을 첫 장면에 넣음(인트로 그림에 들어 있던 제목을 그대로 보여 줌). 끝에서도 한 번 더 보여 줌.
   - 글자 뒤에 옅은 안개 같은 바탕을 깔아 잘 읽히게 함. 글자는 한 줄씩 천천히 떠오름.
   - "먼저 맞혀 보세요 / 부모님과 함께할 시간, 몇 년쯤 남았을까요?" 질문과 선택지(5년쯤·10년쯤·20년쯤·30년 넘게)를 넣고, 고르다 망설이는 장면을 넣음. 최종 선택은 20년쯤.
   - "20년쯤"이 잠깐 남았다 사라짐 → 눈만 내리는 조용한 1.3초 → "16번"(점 16개가 하나씩 켜짐) → "96번(부모님과 함께 먹을 밥, 1년 6번 뵙는 기준)" → "생각보다, 부모님과 함께할 시간은 많지 않을 수 있어요."
   - 만성질환 안내 카드는 따로 떼어 단독 장면으로 만듦(문구·출처 표기는 랜딩 그대로).
   - 눈은 영상 전체에 한 번에 이어서 내리게 함. 결과·안내 장면은 차갑고 어둡게, 마무리는 따뜻하게.
   - 배경음악: 내려받기가 네트워크에서 막혀(프록시 403) 코드로 직접 만든 피아노 곡을 넣음(외부 음원 아님).
5. **판단**:
   - 택: 질문 문구는 랜딩 원문("부모님과…") 그대로. 요청서의 "어머니와 함께 할 시간은…"은 랜딩에 없는 문장이라 쓰지 않음.
   - 택: 96(= 16번 × 1년 6번, 랜딩 계산식)까지만 사용. 기각: 192("이 숫자는 늘릴 수 있어요")는 '시간이 적다'는 흐름과 반대 방향이라 뺌.
   - 택: 끝의 행사명은 새 글꼴로 적음(마무리 그림에는 제목이 그려져 있지 않음).
6. **미확인** (`[확인 필요]`):
   - 팩트 카드 수치 "65세 이상 평균 2.2개 만성질환 / 3개 이상 3명 중 1명" — 랜딩 표기 출처는 "보건복지부·한국보건사회연구원, 2023 노인실태조사". 원자료 대조는 아직 안 함 `[확인 필요]`.
   - 남은 겨울 16번의 근거인 생명표 값 — 랜딩 코드 주석에 "80세 이상은 미확인, 집행 전 KOSIS 값으로 교체 필요"라고 적혀 있음 `[확인 필요]`.
   - 배경음악은 소리를 직접 들어 보지 못하고 음량 수치(-19.3 LUFS, 측정)와 파형으로만 확인함 — 사람 귀로 확인 필요.
7. **다음 할 일**: 강석우 확인 후 공유. 수치 출처 대조. 음악 청취 확인.
8. **개선 단초**: 음원 사이트(Pixabay·Wikimedia·archive.org·incompetech) 접근이 막혀 있음 — 외부 음원이 필요하면 파일을 직접 받아야 함.

   - 4.3–6.4 나이 입력: 내 나이 48 / 어머니 나이 74.

   - 12.0–13.3 숨 고르기: 어두운 화면에 눈만 내림(약 1초).
