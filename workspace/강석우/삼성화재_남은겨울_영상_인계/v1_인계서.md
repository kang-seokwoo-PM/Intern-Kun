## 1. 이 영상이 무엇인가

- 삼성화재 다이렉트 **'부모님과 남은 겨울 계산기'** 랜딩 페이지(v8)를 약 31초짜리 가로(16:9) 영상으로 옮긴 것입니다.
- 20분짜리 비딩 발표 중간에 트는 용도입니다. 그래서 짧고, 한 번에 뜻이 들어오게 만들었습니다. (출처: 지난 작업 로그의 요청 내용)
- 줄거리: "부모님과 함께할 시간은 생각보다 많지 않다" → 나이를 넣는다 → "몇 년쯤 남았을까?" 고민한다 → **16번** → **만성질환 평균 2.2개** → "건강보험부터 점검해 봐요" 버튼을 누른다 → 행사 로고 "우리가 함께할 겨울".
- 화면에 나오는 글자와 숫자는 **전부 랜딩 페이지에 있는 것**입니다. 새로 지어낸 문장은 없습니다. (예외 1개: 행사명 "우리가 함께할 겨울"은 랜딩의 글자가 아니라 인트로 그림 안에 그려진 제목을 옮겨 적은 것)
- 만드는 방법: 랜딩 페이지를 브라우저로 열어 한 장씩(1초에 30장) 사진을 찍고, 그 사진들을 이어 붙여 영상으로 만듭니다. 그래서 랜딩 HTML 파일이 꼭 있어야 다시 만들 수 있습니다.

## 3. 마무리하려면 남은 일 (이 순서대로)

1. **큰 원본 그림으로 바꾸기.** 지금 그림은 랜딩 안에 들어 있던 작은 그림(가로 474픽셀, 800픽셀)을 4배·2.4배로 늘린 것이라 뿌옇습니다. 그래서 일부러 살짝 흐리고 어둡게 깔았습니다. → 4번 (가)
2. **진짜 행사 로고로 바꾸기.** 지금 로고는 Pretendard 글꼴로 적은 임시 글자입니다. → 4번 (나)
3. **진짜 음악으로 바꾸기.** 지금 음악은 코드로 만든 피아노 소리입니다(외부 음원 아님). 사람 귀로 들어 본 적이 없습니다. → 4번 (다)
4. **숫자 확인하기.**
   - `[확인 필요]` **"65세 이상 평균 2.2개 만성질환 / 3개 이상인 분도 3명 중 1명이 넘어요"** — 랜딩에 적힌 출처는 "보건복지부·한국보건사회연구원, 2023 노인실태조사"입니다. 그 보고서 원문과 맞는지 아직 대조하지 않았습니다.
   - `[확인 필요]` **"16번"의 근거인 생명표(남은 수명) 값** — 랜딩 코드 주석에 "확인값: 40·60·65·75세 / 추정값: 80세 이상은 미확인. 집행 전 KOSIS 2024년 생명표 값으로 교체 필요"라고 적혀 있습니다(랜딩 HTML 404–406번째 줄).
     - 영상 속 16번은 어머니 74세로 계산한 값입니다. 산식(랜딩 코드): 65세 여성 23.7년, 75세 여성 14.9년 사이를 나이에 맞춰 나눔 → 23.7 + (14.9 − 23.7) × (74 − 65) ÷ 10 = 15.78 → 반올림 **16**. (계산)
     - 즉 16번에 직접 쓰인 값은 65세·75세 값이고, 랜딩 주석은 이 둘을 "확인값"이라고 하지만 **우리가 KOSIS에서 직접 확인한 적은 없습니다.** 80세 이상 값(추정)은 영상의 나이(74세)를 80세 이상으로 바꾸면 그때 쓰입니다. 둘 다 KOSIS 원자료로 확인이 필요합니다.
   - `[확인 필요]` 마지막 장면의 "삼성화재 다이렉트"는 랜딩 머리글의 글자를 그대로 쓴 것입니다. 공식 로고(CI) 그림이 아닙니다. 공식 CI를 써야 하는지 확인이 필요합니다.

## 4. 따라 하기 — 바꿔 끼우고 다시 만들기

### 준비물 (한 번만)

| 도구 | 확인된 버전 (이 영상을 만든 환경) | 용도 |
|---|---|---|
| Node.js | v22.23.4 | 브라우저를 움직여 사진 찍기 |
| Playwright + Chromium | 1.63.0 | 위와 같음 |
| Python 3 + numpy + Pillow | 3.13.18 / 2.5.3 / 12.3.0 | 그림 준비, 눈, 음악 만들기 |
| ffmpeg | 6.1.1 | 사진을 영상으로 묶기 |
| Pretendard 글꼴 | npm `pretendard@1.3.9` | 화면 글자 |

```sh
cd workspace/강석우/삼성화재_남은겨울_영상_인계/pipeline

npm install playwright            # 이 폴더에 설치 (node_modules는 저장소에 안 올라감)
npx playwright install chromium   # 브라우저 내려받기
pip install numpy pillow
sh get_fonts.sh                   # Pretendard 글꼴을 fonts/ 에 받아 옴
```

이미 다른 곳에 Playwright가 깔려 있으면 `npm install` 대신 위치를 알려 줘도 됩니다:
`export PLAYWRIGHT_PATH=/깔린/위치/node_modules/playwright`

sh run_all.sh "/받은/위치/랜딩_v8.html"

- 문구는 스크립트에 적혀 있지 않고 **랜딩 HTML에서 읽어 옵니다.** 랜딩 HTML이 고쳐지면 그 파일로 다시 돌리기만 하면 됩니다.
- 영상이 기대는 문장이 랜딩에서 사라지면 `build_v5.py`가 "copy not found"라며 멈춥니다. 일부러 그렇게 해 두었습니다(틀린 글자가 조용히 나가는 것을 막으려고).
- 나이(48/74)를 바꾸려면 `render_v5.js`에서 `type('me', '48')`, `type('mom', '74')`를 고칩니다. 그러면 16이라는 숫자도 랜딩 계산식에 따라 바뀌고, 점 개수(`__dots(16)`)도 맞춰 고쳐야 합니다.

## 6. 알려진 한계와, 제가 판단해서 정한 것

**한계**
- 그림이 작습니다(위 3번). 큰 원본을 받기 전까지는 흐림·어둡기로 가리고 있습니다.
- 음악과 심장 소리는 **사람 귀로 들어 본 적이 없습니다.** 음량 수치와 파형으로만 확인했습니다(전체 음량 약 −16.8 LUFS, ffmpeg 측정). 심장 소리는 낮은 소리(56–64Hz 중심)라 노트북 스피커에서는 약하게 들릴 수 있습니다. 발표장 스피커로 꼭 확인해 주세요.
- 이 영상을 만든 환경에서만 다시 만들어 봤습니다(리눅스). 맥·윈도우에서는 글자 굵기나 줄바꿈이 조금 다를 수 있으니 첫 결과를 꼭 눈으로 확인해 주세요. `[확인 필요]`
- 첫 장면 그림은 가로로 넓히려고 같은 그림을 좌우로 뒤집어 이어 붙였습니다. 카메라가 그 이음매와 그림 속 제목 글씨를 비추지 않게 잡아 두었으니, 카메라 숫자를 크게 바꾸면 뒤집힌 제목이 화면에 들어올 수 있습니다.
- 배경 영상(눈 내리는 나무)은 11초짜리를 이어 돌립니다. 이어지는 곳 1초는 겹쳐서 넘깁니다.

**판단한 것 (다르게 하고 싶으면 바꿀 수 있습니다)**
- **임시 로고는 '또렷한 글자' 쪽을 골랐습니다.** 인트로 그림에서 손글씨 제목을 오려 낸 것도 만들어 봤는데, 원래 크기가 약 210×320픽셀이라 화면 크기로 키우면 가장자리가 뭉개지고, 뒤에 있던 나뭇가지 얼룩이 같이 묻어 나왔습니다. 그래서 쓰지 않았습니다.
- **마무리 장면의 설명 두 줄을 뺐습니다**("부모님과 남은 겨울 16번. AI 맞춤보험으로…"). 30–33초 안에 넣고, 버튼 누르는 동작이 잘 보이게 하려는 이유입니다. 대안: 살리려면 `ls_v5.css`의 `.hero .close-s{display:none}`을 지우고 `PRESS`를 1.5초쯤 늦춥니다(전체가 약 32초가 됨).
- **마무리 장면의 작은 행사명 줄을 뺐습니다.** 바로 뒤에 로고 장면이 나와서 같은 말이 두 번 나오기 때문입니다.
- **2.2 장면은 한 문장을 한 줄로 두고 숫자만 크게 키웠습니다.** "65세 이상 부모님들은 평균 [2.2개] 의 만성질환을 갖고 계세요." 문장 순서는 랜딩 그대로입니다. 랜딩에 있던 노란 밑줄은 숫자가 강조를 대신하므로 뺐습니다. 대안: 숫자를 위, 문장을 아래로 쌓는 배치.
- **첫 장면은 인트로 문단 4줄 중 1·2·4번째 줄만 썼습니다.** 3번째 줄("언제까지나 그 자리에 계실 것 같지만,")은 시간을 맞추려고 뺐습니다. 4번째 줄은 화면 폭에 맞춰 "시간은" 뒤에서 줄을 바꿨습니다(글자는 그대로).
- **버튼은 '누르는 모습'만 보여 줍니다.** 진짜로 누르지 않았고, 신청서에 아무것도 넣지 않았습니다. 진짜로 누르면 랜딩이 "이름을 넣어 주세요" 오류를 띄우기 때문이기도 합니다.
- **16번이 가장 세고, 2.2는 그다음**이 되게 했습니다. 2.2는 더 짧고(떨어지는 시간 0.26초), 번쩍임이 약하고, 음악 강세도 16번의 약 60% 크기입니다(파형 최고값 0.52 대 0.84, 측정).
- 심장 박동 뒤에는 숫자와 카메라가 **완전히 멈춥니다.** 계속 두근거리지 않습니다.
