# pipeline_B — 비교용 "B안" 영상 만드는 도구 (B1)

A안(v6, `../pipeline/`)은 랜딩 화면을 그대로 움직여 찍은 영상이고, **B안은 화면 녹화가 아니라 "보는 사람에게 묻는 영상"** 입니다.
마지막 약 7초(마무리 화면과 버튼) 전까지는 버튼·입력칸·포인터가 하나도 나오지 않고, 그림·눈·글자만 나옵니다.

## 한 번에 만들기

```sh
sh run_all_B1.sh <랜딩 v8 HTML 경로>      # 결과: out/samsung_winters_16x9_B1.mp4
```

글꼴·그림·로고·피아노 샘플·눈은 `../pipeline/` 것을 같이 씁니다(따로 복사하지 않음). 준비물은 `../v2_인계서.md`, 소리 출처는 `../pipeline/SOUNDS.md`.

## 파일

| 파일 | 하는 일 |
|---|---|
| `build_B1.py` | 랜딩 HTML에서 문구를 그대로 꺼내 영상용 페이지(`work/film_B1.html`)를 만듦. **새 문구 2줄은 맨 위 `NEW_LINE_1`, `NEW_LINE_2`** |
| `film_B1.js` | 영상 전체의 시간표와 움직임. 맨 위 `T = {...}`의 숫자(초)만 바꾸면 그림과 음악이 함께 따라옴 |
| `film_B1.css` | 글자 크기·위치·배경 어둡기 |
| `render_B1.js` | 페이지를 1초에 30장씩 찍음. 화면에 나온 글을 시간순으로 적고, 7번 장면 전에 버튼 화면이 보이면 오류로 멈춤 |
| `music_B1.py` | 음악(악기와 후처리는 v6과 같고 악보만 새로 씀) |
| `assemble_B1.py` | 눈 + 음악을 얹어 mp4로 만듦. `--music 파일`로 완성된 음악을 대신 넣을 수 있음 |
| `sheet_B1.py` | 확인용 장면 모음 사진 만들기 |

## 문구 규칙

- 새 문구 2줄(`NEW_LINE_1`, `NEW_LINE_2`)은 **승인 전 초안**입니다. 나머지는 전부 랜딩 HTML에서 읽어 온 그대로이고, `build_B1.py`에 다시 적지 않습니다.
- "96번"은 랜딩과 같은 계산입니다: 16번 × 1년 6번 = 96 (산식 출처: 랜딩 HTML의 `meet: main.w * S.freq`).
