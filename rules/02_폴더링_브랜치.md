# 02. 폴더링 · 파일명 · 브랜치 · 충돌 방지

## 폴더
| 위치 | 용도 | 누가 쓰나 |
|---|---|---|
| `workspace/<이름>/` | 본인 작업물 | 본인만 쓴다. 남의 폴더는 수정하지 않는다 |
| `logs/` | 날짜별 작업 기록 | 1인 1파일 |
| `rules/`, `CLAUDE.md`, `AGENTS.md`, `README.md` | 규칙·구조 | 규칙 브랜치(`rules/…`)에서만 변경 |
| `STATE.md` | 현재 상태 | 한 번에 한 작업자만 갱신 |

`<이름>`은 **한글 이름**(이메일·GitHub ID 아님). 

## 파일명
- 산출물: `vN_내용_YYMMDD.확장자` (예: `v1_주간리포트_261112.md`)
- 로그: `YYMMDD_이름_내용.md`
- **이미 커밋된 `vN_` 파일은 수정하지 않는다.** 고치면 `v(N+1)_`로 새로 만든다.

## 충돌 방지 3장치
1. **vN 불변** — 커밋된 버전 파일은 덮어쓰지 않는다.
2. **1인 1파일 로그** — 로그는 사람별로 파일을 나눠 같은 파일을 동시에 고치지 않는다.
3. **STATE 단독 소유** — 같은 시점에 STATE.md를 고치는 사람은 한 명. 다른 세션이 돌고 있으면 로그에만 쓴다.

## 브랜치
| 종류 | 이름 | 건드려도 되는 곳 |
|---|---|---|
| 개인 작업 | `work/<사람>-<작업>` | `workspace/<이름>/`, `logs/` |
| 규칙·문서 | `rules/<사람>-<작업>` | `rules/`, `CLAUDE.md`, `AGENTS.md`, `README.md`, `팀원_시작하기.md`, `CHANGELOG.md` |
| 실험 | `try/<사람>-<작업>` | 버려도 되는 시도 |

- **브랜치 하나는 목적 하나.** 규칙 브랜치에 개인 작업물을, 작업 브랜치에 규칙 파일을 커밋하지 않는다.
- 커밋 전에 `git branch --show-current`와 `git diff --cached --stat`으로 확인한다.
- **`main`에는 팀장(강석우)만 push한다.** 다른 팀원과 클사원은 항상 이름 브랜치에 쌓고(push) PR로 올린다. 병합은 팀장이 한다. 클사원은 누가 요청해도 `main`에 직접 push하지 않는다.
- **`git push --force` 금지.** 충돌 시 한쪽을 버리지 않고 양쪽 내용을 살려 합친다.
- 커밋 메시지: `[분류]: 무엇을` 한 줄. 예) `[work]: 주간 성과 리포트 v1`

## Slack 호출 세션에서의 규칙
- 호출로 시작한 세션이 지정받은 브랜치가 있으면 **그 브랜치에만** push한다.
- PR은 사용자가 요청했을 때만 만든다. PR 설명에 Slack 스레드 링크를 포함한다.
