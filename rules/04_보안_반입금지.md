# 04. 보안 · 반입 금지

> **이 저장소는 공개(public)일 수 있다.** 올리는 순간 누구나 볼 수 있다고 전제한다.

## 저장 금지 (절대)
- API 키·토큰·비밀번호·인증정보(`.env`, `credentials*.json`, `*.pem`, `secrets*`).
- 개인정보(이메일·전화·주민번호 등), 팀원 개인 계정 핸들 목록.
- 광고주 원본 데이터·로우데이터·RFP/OT 원본·NDA 대상 자료.
- 특정인 성과 수치(커리어 맥락 외), 인사정보.
- 1MB 초과 바이너리(이미지·영상·pptx·psd 등) — 꼭 필요하면 경로·링크로.

## 키·민감정보
- 키는 코드·로그·답변에 출력하지 않는다. 암호화 보관이 필요하면 BIDDING의 키 관리 방식(`keys/env.enc`)을 따른다.

## 실수로 올렸다면
- 즉시 강석우·김재민에게 알리고, history 포함 제거 절차를 밟는다. 공개 노출은 이미 캐시·인덱싱됐을 수 있으니 키는 **폐기·재발급**한다.

## 저장소 공개 범위
- 팀 공용 작업 저장소는 **비공개(private) 권장.** 공개 상태로 둘지 여부는 강석우 팀장이 판단한다.
