# 03. 보안 · 반입 금지

이 저장소는 팀 공용이다. **비공개(Private)를 유지**하고, 아래는 **절대 커밋하지 않는다.** 스레드에도 옮기지 않는다.

- 개인정보: 주민번호, 연락처, 개인 이메일·계정 목록 등 (팀원 명부는 별도 관리, 이 저장소에 복제하지 않는다)
- **인사 정보**: 평가·징계·연봉·채용 판단 등. 대화에서 나와도 산출물·로그에 옮기지 않는다
- 인증정보: API 키, 토큰, 비밀번호, 쿠키
- 광고주·고객 원본 데이터, 타사 내부자료
- NDA 대상 문서 원본 (RFP 원본 등) — 필요하면 위치(경로)만 기록
- 사내 서버 경로의 원본 파일 (읽기 전용으로만 참조, 쓰기·이동·삭제 금지)
- 1MB 넘는 파일 · 바이너리 덩어리

판단이 애매하면 **올리지 말고 묻는다.** 이미 올라간 의심 파일을 발견하면 삭제하지 말고(이력에 남음) 팀장에게 알려 처리 방법을 정한다.
